# Security

Kexts run in the kernel. If you find a security problem in OpenKext's own code (the registry bot, the site), or a listed release that looks malicious or tampered with, don't open a public issue. Use GitHub's private vulnerability reporting on the affected repository ("Security" tab, "Report a vulnerability").

Problems in a listed project belong to that project; report them there. If the project doesn't respond and the problem puts users at risk, tell us the same way and a maintainer will review its listing.
