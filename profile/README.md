# OpenKext

A shared home for open-source macOS drivers on hackintosh hardware: the kexts, the ports, and the notes on how they were made.

- **[Registry](https://github.com/openkext/registry):** the catalog. Anyone can list an open-source driver or report a test. Fixed rules approve what they cover, and other people's test reports decide a driver's status.
- **[Site](https://openkext.github.io):** the catalog and the guides in a readable form.
- **Guides:** how to write and port macOS drivers without crossing Apple's license, with real projects as examples.

Projects keep their own repositories and licenses. OpenKext lists them, checks their releases, and collects test reports.

Start here: [submit a project](https://github.com/openkext/registry#submit-a-project) or [report a test](https://github.com/openkext/registry#report-a-test).
